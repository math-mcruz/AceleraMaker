# AceleraMaker - Montreal
Treinamento com projetos semanais voltados ao desenvolvimento de habilidades profissionais.

## Projetos
- [ ] Projeto semanas 1 e 2: Sistema Bancário, funcionalidades financeiras básicas, menu interativo, persistência de dados, testes, validações e tratamento de dados.

- [ ] Projeto semanas 3 e 4: Blog Pessoal, criação de APIs modernas utilizando ASP.NET Core, mapeamento de entidades, relacionamento entre tabelas, boas práticas de arquitetura em camadas, segurança de APIs RESTful, persistência de dados, implemetação de funcionalidade básica utilizando integração com API de IA.
